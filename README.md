# capstone2026
This is the repository that contains the implementation for Data at Bat by the team Non-Evil Palantir.

## Getting Started

To run this project locally, follow these steps:

1. **Clone the repository:**

    ```bash
    git clone https://github.com/your-username/capstone2026.git
    ```

2. **Install flutter dependencies:**

    ```bash
    cd capstone2026/app
    flutter pub get
    ```

3. **Run the application:**

    ```bash
    flutter run
    ```
