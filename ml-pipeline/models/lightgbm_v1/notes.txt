ML Pipeline Notes (Current State)
=================================

Goal
----
Predict home team win probability for MLB games and compare model probability
to sportsbook implied probability to estimate edge.


Data Sources / APIs
-------------------
1) MLB Stats API
   https://statsapi.mlb.com/api/v1/
2) The Odds API
   https://the-odds-api.com/


Primary Scripts and Outputs
---------------------------
Orchestrator
  scripts/run_pipeline.py
    Modes:
      --mode data      -> data fetch + matching + upcoming dataset prep
      --mode train     -> historical results + dataset build + model train
      --mode predict   -> run predictions only
      --mode full      -> data + train + predict

Data Fetch / Build Scripts
  data/fetch/fetch_schedule.py
    Output: data/raw/schedule.csv
    Pulls schedule rows with teams, game_id, date, probable pitchers, status.
    Current window: around today (today - 3 days to today + 3 days).

  data/fetch/fetch_odds.py
    Output: data/raw/odds_raw.csv
    Pulls h2h odds across bookmakers, stores each outcome row.

  data/fetch/match_odds_to_games.py
    Output: data/processed/odds_matched.csv
    Matches odds rows to schedule by normalized home/away team names and date.
    Strict match rule: keep only date_diff_days <= 1 and nearest match.

  data/fetch/build_odds_features.py
    Output: data/processed/odds_features.csv
    Collapses bookmaker rows to one row per game_id:
      - home_moneyline, away_moneyline
      - home_implied_prob, away_implied_prob
    Uses best bettor price (max) per side before implied probability conversion.

  data/fetch/build_upcoming_dataset.py
    Output: data/processed/upcoming_games_with_odds.csv
    Joins schedule + odds features for upcoming games.

  data/fetch/fetch_pitcher_stats.py
    Output: data/raw/pitcher_stats.csv
    Pulls pitcher stats for upcoming game pitchers:
      - era, whip, innings_pitched, strikeouts

  data/fetch/fetch_game_results.py
    Output: data/raw/game_results.csv
    Pulls historical completed game results:
      - home_score, away_score, home_win label
    Defensive fix in place: skips games where linescore exists but runs missing.

  data/fetch/build_dataset.py
    Output: data/processed/model_dataset.csv
    Builds historical training dataset by joining schedule + results.

  data/fetch/merge_odds_into_dataset.py
    Output: data/processed/model_dataset_with_odds.csv
    Utility merge for joining historical model dataset with odds features.
    (Current training script does not consume this file yet.)


Model Training
--------------
Script
  models/lightgbm_v1/train.py

Model
  lightgbm.LGBMClassifier
    n_estimators=150
    learning_rate=0.05
    num_leaves=15

Training toggles (current)
  train.py supports quick ablation and parameter control:
    --feature-set base8|full12
    --n-estimators <int>
    --num-leaves <int>
    --learning-rate <float>

  Example ablation runs:
    python "ml-pipeline/models/lightgbm_v1/train.py" --feature-set base8
    python "ml-pipeline/models/lightgbm_v1/train.py" --feature-set full12

Training features (current)
  Categorical IDs:
    - home_team_id
    - away_team_id
    - home_pitcher_id
    - away_pitcher_id
  Pitcher stats:
    - home_pitcher_era
    - away_pitcher_era
    - home_pitcher_whip
    - away_pitcher_whip
  Team form:
    - home_team_win_pct
    - away_team_win_pct
    - home_last10_win_pct
    - away_last10_win_pct

Feature engineering inside train.py
  1) Adds pitcher stats by joining pitcher_id to home/away pitcher IDs.
  2) Missing pitcher features are median-imputed.
  3) Builds team form features from prior games only (leakage-aware):
       - cumulative win% before current game
       - rolling last-10 win% before current game
  4) Missing team form values default to 0.5.

Train/Test split (current)
  Time-based chronological split:
    first 80% rows by date = train
    last 20% rows by date = test

Metrics printed
  - Accuracy
  - Log loss (primary probability-quality metric)

Model artifact
  Output: models/lightgbm_v1/model.pkl


Prediction / Edge Script
------------------------
Script
  scripts/predict_upcoming_games.py

Inputs
  - data/processed/upcoming_games_with_odds.csv
  - data/processed/model_dataset.csv (for team form lookup)
  - data/raw/pitcher_stats.csv
  - models/lightgbm_v1/model.pkl

Process
  1) Adds pitcher ERA/WHIP features to upcoming rows.
  2) Builds team-level form lookup from historical dataset:
       - overall win%
       - last-10 win%
     then merges onto upcoming home/away teams.
  3) Predicts model_home_win_prob.
  4) Computes edge = model_home_win_prob - home_implied_prob.
  5) Sorts by edge descending.

Edge filtering (current analysis band)
  MIN_EDGE = 0.03
  MAX_EDGE = 0.30
  MIN_MODEL_PROB = 0.45
  MAX_MODEL_PROB = 0.75

Prediction outputs
  - data/processed/predictions.csv            (all rows)
  - data/processed/predictions_filtered.csv   (edge + model_prob filtered rows)


Current Known Caveats
---------------------
1) LightGBM often warns about sparse categorical IDs and many no-gain splits.
   This indicates limited predictive signal and/or high-cardinality ID features.

2) Team form in prediction is aggregated from the full historical dataset, not
   explicitly cut off to "as-of prediction date" in script logic. This should be
   tightened later for strict real-time leakage control.

3) model_dataset_with_odds.csv exists but is not currently used by train.py.

4) Edge thresholds are currently for analysis/screening, not final staking logic.
5) Use feature-set ablation (base8 vs full12) to verify that new features
   actually improve log loss before keeping them.
